# sw-ncs-backports
This repository contains **Ethernet backport patches for Microchip PCI1xxxx devices**.

The content in this folder is limited to **backported patches only**, intended to bring Ethernet-related updates, fixes, or functionality from newer upstream sources into kernels where they are not yet available.

---

## Notes

- Review each patch carefully before applying
- Conflicts may occur depending on kernel version
- Testing on target hardware is required
- Patch notes are provided in the respective kernel folders
